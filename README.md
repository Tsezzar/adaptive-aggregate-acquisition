# Adaptive aggregate acquisition

Материалы воспроизведения исследования «Адаптивный запрос агрегатов с совместным линейным выводом».

[Скачать архив v1.0.0](https://github.com/Tsezzar/adaptive-aggregate-acquisition/releases/tag/v1.0.0)

Архив содержит реализации процедур, конфигурации, сохранённые результаты и инструкции для воспроизведения расчётов ACS, CPS, РМЭЗ, ОРС и ONS. Начните с README.md внутри архива. Исходные российские микроданные получают у организаций — владельцев обследований.

Файл `injoit-reproducibility-v1.0.0.zip`. Размер 144068882 байт.

SHA-256 `5ed2b31ff3e53c8f9485aabb7fe72cc60dece649901b01c0a6635d311be182d0`.

В сравнении с MinimumElement исполнена описанная в статье адаптация. Выигрыш относится к совместной процедуре вывода ячеек и выбора запросов. Эксперименты используют точные эмпирические агрегаты и модельную цену ячеек и обращений.
